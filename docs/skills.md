# Skills

Skills use the portable `SKILL.md` format: YAML frontmatter for discovery and
a body containing the operating method. The important skills are in
`skills/debugging`, `skills/product-discovery`, `skills/growth-experiment`,
`skills/tdd`, `skills/code-review`, and `skills/compound-learning`.

They are methodology, not completion evidence. The runtime still requires
tool, review, metric, or human evidence as appropriate.
